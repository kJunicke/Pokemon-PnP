[[Attacken]]

Gräbt sich ein um vom Boden aus zu attackieren

| [[Typ]]                 | Boden    |
| ----------------------- | -------- |
| [[Kategorie]]           | physisch |
| [[Genauigkeit]]         | 0        |
| [[Reichweite]]          | nah      |
| [[Ausdauer\|AP-Kosten]] | X (1)    |
| Schadenswürfel          | 1W10     |
#### Effekt
- Pokémon erhält den Aspekt vergraben
- Das [[Pokémon]] kann sich ausbuddeln und vom Boden aus attackieren, wenn es sich unter einem Gegner befindet
- [[Pokémon]] zahlt jeweils 1 AP für:
	- Vergraben
	- Bewegen
	- Angreifen
